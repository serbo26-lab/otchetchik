# Отчетность УК 728/пр — README-память проекта до V1.5.9

## Назначение программы

Локальная Windows-программа для формирования отчетов управляющей организации по форме Приложения № 2 к приказу Минстроя России № 728/пр.

Главная задача текущей ветки — надежный генератор официального отчета:

- управляющие организации;
- дома;
- категории и подкатегории работ;
- справочник работ/услуг;
- шаблоны перечней;
- отчеты по домам и годам;
- раздел 1 — содержание общего имущества;
- раздел 2 — текущий ремонт;
- раздел 3 — стоимость услуг управления;
- раздел 4 — претензионно-исковая работа;
- раздел 5 — начисления и поступления;
- массовое заполнение строк в несколько отчетов;
- экспорт в XLSX, DOCX и PDF.

Официальная форма защищена: в официальный отчет выводятся только поля формы 728/пр. Категории, шаблоны и массовое заполнение нужны для удобного заполнения этих официальных строк.

## Основные правила архитектуры

1. Поле `Раздел формы` определяет, куда строка попадает в отчете:
   - `Содержание` → раздел 1;
   - `Текущий ремонт` → раздел 2;
   - `Управление` → раздел 3.

2. Категории и подкатегории нужны для быстрого создания строк справочника и шаблонов.

3. Шаблон применяется только в своем разделе:
   - шаблон содержания — только в разделе 1;
   - шаблон текущего ремонта — только в разделe 2;
   - шаблон управления — только в разделе 3.

4. В разделе 3 официальный отчет выводит только итоговую сумму. Строки управления внутри программы нужны для удобного заполнения этой суммы.

5. Массовое заполнение — инструмент генератора отчета, позволяющий добавить выбранную работу/услугу сразу в несколько отчетов.

6. Год отчета может быть 2025 и далее. Программа может использоваться в 2026 году для подготовки отчета за 2025 год.

7. В строках раздела 1 действует простая формула официальной формы: `цена единицы × количество = стоимость`. Если исходная ставка задана за месяц, массовое заполнение должно преобразовать ее в цену за отчетный период.

## Массовое заполнение

В массовом заполнении пользователь выбирает:

- УО;
- год;
- услугу/работу из справочника;
- способ расчета;
- нужные параметры;
- режим создания отсутствующих отчетов;
- режим обновления уже существующей строки.

Перед записью всегда показывается предпросмотр.

### Способы расчета

- `Цена за 1 м² площади дома` — ставка уже дана за весь отчетный период. В строку отчета попадает: цена = ставка, количество = площадь дома.
- `Цена за 1 м² в месяц` — ставка дана за месяц. Пользователь вводит количество месяцев, по умолчанию 12. В строку отчета попадает: цена = месячная ставка × месяцы, количество = площадь дома.
- `Готовая сумма на один дом` — в каждый выбранный отчет добавляется готовая сумма.
- `Общая сумма на несколько домов, распределить по площади` — общая сумма распределяется между домами пропорционально официальной площади дома.
- `Цена × количество` — пользователь вводит цену за единицу и количество.

### V1.5.9 MONTHLY RATE FIX

- добавлен способ массового заполнения `Цена за 1 м² в месяц`;
- для этого способа отображается поле `Количество месяцев`, по умолчанию 12;
- расчет выполняется так: месячная ставка × месяцы × площадь дома;
- в официальную строку отчета записывается цена за период, то есть `месячная ставка × месяцы`, а количество остается равным площади дома;
- выпадающие списки шаблонов и добавления из справочника дополнительно проверены и усилены: фильтрация по разделам работает через нормализацию значения `Раздел формы`, а не только через точное совпадение текста.

## Правила будущих билдов

- Каждый билд — чистый архив, без старых BAT, README внутри архива, временных баз, экспортов и `__pycache__`.
- README-память присылать отдельным файлом, не внутри архива.
- Не смешивать официальный генератор отчета с отдельным расчетным модулем.
- Новые функции добавлять только после стабилизации ядра.
