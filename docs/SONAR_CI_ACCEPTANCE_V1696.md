## Воспроизводимая проверка журнала

Из корня полного репозитория: `Get-Content -Raw decoded-job-log.txt | python scripts/audit_ci_log.py` (PowerShell) или `python scripts/audit_ci_log.py < decoded-job-log.txt` (bash). Проверяются все test_*.py, наличие ровно одного полного запуска каждого модуля, ненулевое количество тестов, OK без skipped/expected failures и отсутствие лишних модулей. Focused-тесты до списка модулей не удваивают счетчик. Добавлены два теста самого парсера.

Проверять отдельно: Sonar Quality Gate и полный список открытых issues, успешность всех шагов Windows CI, точный SHA head, отсутствие пропуска тестов, smoke-test EXE и опубликованный SHA-256. Не изменять правила анализа и CI для получения зеленого результата. Не считать статический аудит или текущий промежуточный результат финальной приемкой.
